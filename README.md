# Server Log Analysis Dashboard

## Problem Statement

Server log files contain valuable information about application activity, errors, requests, and system performance. However, analyzing raw log files manually can be time-consuming and difficult.

This project provides an interactive dashboard that processes server logs and presents useful insights through visualizations and statistics.

## My Contribution

- Developed the log analysis application.
- Implemented log file processing and data extraction.
- Created an interactive dashboard to visualize server activity.
- Added analysis of important log metrics such as requests, errors, status codes, and activity patterns.
- Organized the project for easy upload and analysis of log files.

## Tech Stack

- **Programming Language:** Python
- **Framework:** Streamlit
- **Data Processing:** Pandas
- **Data Visualization:** Plotly
- **Log/Data Handling:** JSON, CSV and log files

## Key Features

- Upload and process server log files
- Analyze server requests and responses
- Identify error patterns
- View HTTP status code distribution
- Interactive charts and statistics
- User-friendly dashboard interface
